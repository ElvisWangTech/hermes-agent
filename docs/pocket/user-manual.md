# Pocket 用户手册

Pocket 是一个手机网页应用：你对着一个形象说话，屏幕上同时出现字幕。它背后是一个只属于你的 Hermes 助手，会记住你给她起的名字和你的介绍。

本手册面向使用 Pocket 的用户。管理员相关内容见 `hermes-cube-provider/docs/admin-manual.md`。

## 1. 开始之前

你需要：

- 一部手机（推荐使用 Safari 或 Chrome 的最新版本）。
- 管理员提供的**连接码**和**访问地址**。
- 如果要用语音说话，需要允许浏览器使用麦克风。

注意：

- **连接码只能使用一次，默认 10 分钟内有效。** 过期或用过后，请向管理员重新索取。
- 连接码相当于你的登录凭证，不要转发给别人。
- 语音需要浏览器的安全连接（HTTPS 地址）。如果你打开的地址不是 HTTPS，麦克风可能不可用，此时可以直接打字。

## 2. 第一次使用

1. **打开地址，输入连接码。** 如果管理员给了二维码，直接扫码即可跳过输入。
2. **允许麦克风。** 允许后可以直接说话；拒绝也没有关系，你可以全程打字。
3. **选形象。** 先选年龄段（低龄、少年、青年），再左右滑动选择角色。选中后形象固定，第一版不能中途更换。
4. **给她起名字。** 她会请你给她起一个名字。你可以说，也可以打字。她会把名字重复一遍，你点击确认。
5. **介绍你自己。** 她会请你说说你是谁，例如"我叫……，你可以叫我……"。称呼和可选介绍由你核对后保存。这一步确定你是这个助手的主人。
6. **完成。** 之后每次打开，直接进入主画面。

**关于"主人"**：完成介绍后，你就是这个助手的唯一主人。第一版不支持更换主人、改名或转让。如果需要重新开始，请联系管理员。

## 3. 日常使用

- **说话**：按住或点击麦克风（以界面提示为准），说完后她会回答。她的回答会以语音朗读，同时显示字幕。
- **打字**：如果语音不可用，或者在安静的环境里，直接在输入框打字即可。
- **确认卡片**：她有时会请你确认一件事（比如执行某个操作或补充信息），屏幕底部会出现一张卡片，点击选择即可。
- **历史会话**：可以查看之前的对话，并从历史中继续。
- **日程**：可以让她记下待办或定时提醒。她会先请你确认，确认后才会生效。
- **重新连接**：如果网络断开，可以在设置里点击重新连接。如果一直连不上，请稍后再试。

## 4. 你的数据

- 你给她起的名字、你的称呼和你的介绍，会保存在你的助手记忆中，用于下次对话时认出你。
- 你的对话内容保存在你的助手那里。管理后台没有查看对话内容的功能。
- 语音录音默认只用于当次处理，不会长期保存。
- 第一版不提供自助删除助手的功能。如需删除，请联系管理员。

## 5. 当前版本的限制

| 功能 | 状态 |
|---|---|
| 文字对话、语音对话 | 可用（语音依赖浏览器麦克风权限） |
| 起名、认主、介绍 | 可用 |
| 声纹识别 | **未开放**（第二阶段） |
| 自助删除助手、换人、改名 | 不提供，需联系管理员 |
| 多台手机同时使用 | 每台手机需要单独的连接码（由管理员签发） |

## 6. 常见问题

**Q：连接码输入后提示无效？**
A：连接码可能已过期（10 分钟）或已经用过。请向管理员重新索取。

**Q：提示需要麦克风，但我已经允许了？**
A：检查地址是否为 HTTPS；检查浏览器设置里是否允许该网站使用麦克风。仍不行就先用打字。

**Q：她没有声音？**
A：检查手机是否静音，以及页面上的朗读开关是否打开。语音朗读失败时，字幕仍会显示。

**Q：提示"正在唤醒"？**
A：你的助手可能处于休眠状态，正在恢复。通常几秒到几十秒就能完成，请稍等，不必重复提交。

**Q：换了一部手机怎么办？**
A：每台手机需要单独的连接码。请管理员为新手机签发一个。旧手机的登录会保持有效，直到管理员撤销。

**Q：我的手机丢了怎么办？**
A：立即联系管理员撤销该设备，避免别人继续使用你的助手。

**Q：她记不住我的名字？**
A：名字在认主和介绍时保存。如果没有完成这一步，她会重新请你起名。如果已经完成却记不住，请联系管理员检查。

## 7. 给开发者：OpenAI 兼容接口

如果你需要通过程序调用助手，可以使用 OpenAI 兼容接口。请向管理员申请 API key。

- 基础地址：`<管理员提供的地址>/v1`
- 认证：请求头 `Authorization: Bearer <你的 API key>`
- 支持的接口：`/v1/chat/completions`、`/v1/models` 等。

API key 只能访问分配给你的助手，不能访问其他助手的数据。请妥善保管，不要提交到代码仓库或公开场合。

## 8. 联系方式

使用中遇到问题、需要重新签发连接码或撤销设备，请联系管理员。
